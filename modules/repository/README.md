# repository

Creates an org repository with the org-wide rules baked in, so no repo can be
created without them:

- Squash merge only, PR title as the commit title, branch deleted on merge.
- A ruleset on the default branch: PR required, squash only, no force push,
  no deletion, linear history.
- Secret scanning and push protection on public repos.
- `archive_on_destroy`: removing a repo from the root archives it.

`ruleset_enforcement = "disabled"` exists only for the bootstrap, before a
repo's history has been pushed. `required_status_checks` must list only checks
that run on every PR, or a PR that skips one can never merge.
